AI-NATIVE ENGINEERING (SDD)

  • End-to-end spec-first workflow: every deliverable starts as a spec (scope, out of scope, decisions and Given/When/Then criteria), becomes a plan of verifiable steps, and only then is executed by agents. Specs, plans and reviews are versioned alongside the code.
  • Deterministic execution on top of LLMs: I created a skill (sdd-plan-runner) that executes plans step by step and blocks progress on a failing test. It forbids loosening a criterion or a test just to "make it pass", has mandatory stop points for human decisions (human-in-the-loop), and resumes partially executed plans.
  • Agent orchestration: per-task subagents (implementation, code review, verification before completion), parallel agents for independent tasks and isolation through git worktrees.
  • Context engineering: AGENTS.md/CLAUDE.md per repository with non-negotiable architectural rules (repository pattern, auditing, ACL, i18n, UI standards) and a context documentation base that works as the project's memory. This keeps agent-generated code consistent across features and across developers.
  • Quality as a gate, not a stage: unit, integration and e2e tests required for every feature, code review and blocking CI before merge and deploy.
